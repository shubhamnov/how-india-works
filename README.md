# How India Works

An interactive, static civics-learning website about the institutions, decisions and public services that shape everyday life in India.

## Current experience

- Responsive homepage and four learning worlds.
- A playable scenario about identifying the authority responsible for a damaged road.
- Choice-based explanations and a follow-up step about reporting and accountability.
- Self-contained HTML, CSS and JavaScript; no framework, backend, database, external API or build step.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose `main` and the `/(root)` folder, then save.
4. Wait for GitHub Pages to publish the site.

## Project principles

- Teach through real-world scenarios and decisions, not only quizzes.
- Explain why an answer is correct and how institutions connect.
- Keep the experience politically neutral.
- Distinguish constitutional responsibilities from state-, local-body- and project-specific arrangements.
- Use authoritative sources when adding factual content.

## Roadmap

1. Expand Everyday India with water, sanitation, public health and other services.
2. Add an interactive elections journey covering constituencies, MPs, MLAs and government formation.
3. Add a Parliament and lawmaking journey.
4. Add public budgets, procurement, infrastructure projects and business regulation.

The site is intentionally static. Shared accounts, live data and multiplayer features are out of scope.
